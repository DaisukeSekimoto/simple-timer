# Simple Timer

日報に記載する作業時間を、1日単位で記録するシンプルなタイマーです。

カウントダウンとストップウォッチに対応しており、計測した作業を当日の履歴として保存できます。サーバーやアカウントは不要で、GitHub Pagesなどの静的サイトとして公開。

## 主な機能

- カウントダウン／ストップウォッチの切り替え
- 指定時刻までの時間を、作業時間の単位・休憩時間からポモドーロとして自動構成
- カウントダウン0秒時の終了音量を整数で設定・試聴（初期値50%、スライダー表示は最大100%）
- 計測した作業を当日の日付で記録
- 日付を選択して過去の作業履歴を表示
- 前日以前の履歴を既定で参照専用にし、設定から5分間だけ編集を許可
- 計測を継続したまま別のタイマータブへ移動し、開始時に計測対象を切り替え
- タスク別の件数・合計時間を表で集計し、タスクごとのメモを一覧表示
- タスクのメモ一覧右上に件数と合計時間を表示（合計時間のクリックで共通の時間表記を切り替え）
- 出退勤時間と休憩時間を登録し、休憩控除後の勤務時間・計測時間・差分を日別に表示する勤務集計
- タイマーを使わなかった作業履歴を日付・タスク名・作業時間の手入力で追加
- 保存されている全履歴をTXTファイルとして一括出力
- 作業時間を「分」または「hh:mm:ss」で表示
- 最近使用したタスク名を最大10件表示
- タイマーの小窓表示
- Picture-in-Picture内でのタスク名入力・履歴表示・履歴追加
- 端末・ブラウザごとの履歴保存

## 使い方

1. 必要に応じて「タスク名を入力」を押し、作業名を入力します。
2. カウントダウンまたはストップウォッチを選択します。
3. 「開始」を押して計測を始めます。タスク名が未入力でも計測できます。
4. 作業が終わったら「次の作業に移る」を押します。
5. 計測結果が今日の履歴に保存され、追加完了の通知が数秒間表示されます。

ポモドーロを有効にして「作業時間」の変更画面から終了時刻を指定すると、作業時間の単位と休憩時間を設定できます。終了時刻まで作業と休憩を交互に配置して休憩回数を自動計算し、端数は最後の作業時間へまとめます。最後の作業回が終わると、次の休憩には移らずポモドーロを完了します。

「次の作業に移る」を押した時点でタスク名が未入力の場合は、タスク名の入力画面が表示されます。タスク名を決定すると、直前の計測結果がその名前で保存されます。

「リセット」を押すと、計測時間と入力中のタスク名が初期化されます。カウントダウンが0秒を過ぎると、超過時間を赤字の `+hh:mm:ss` で表示します。

画面右上の「履歴」から日付を選択すると、過去の記録を確認できます。履歴画面の初期日付は今日です。履歴と勤務集計の時間表記は共通で、設定から既定値を「分」または「hh:mm:ss」に変更できます。どちらかの画面で表示形式を切り替えた場合も、両画面へ一時的に反映されますが、ページ更新時には設定画面で保存した既定値へ戻ります。分表示では秒数を四捨五入します。

前日以前の履歴は参照専用です。修正が必要な場合は「設定」の「過去の履歴編集を5分間許可する」をONにしてください。編集許可中も登録済みの日付一覧を確認でき、履歴がない過去の日付は併設されたカレンダーから選択できます。未登録の日付を選んだ場合は一覧に「未登録」と表示されます。この許可は5分後、またはウィンドウを閉じた時点で自動的に解除され、ブラウザには保存されません。

計測中に別のタイマータブを選んでも、計測はバックグラウンドで継続します。バックグラウンドで計測中のタブは紫色に点滅します。別のタブで「開始」を押すと、計測中のタブを一時停止して切り替えるか確認します。同時に計測できるタスクは1件だけです。

履歴画面には、その日の記録件数と合計時間が表示されます。出勤・退勤時刻を登録した日は、2行目に出退勤時間の範囲と休憩控除後の勤務時間も表示されます。集計ボックスから勤務集計を開くと、タスク別の合計とメモ、勤務時間と計測時間の差分を確認できます。出勤・退勤を初めて入力した際の休憩時間は1時間です。勤務集計内の時間は「mm表記」と「hh:mm:ss表記」を切り替えられます。

履歴画面の「全履歴をTXT出力」を押すと、保存されているすべての日付の記録を1つのTXTファイルとしてダウンロードできます。画面上で選択している表示形式にかかわらず、作業名、分、`hh:mm:ss`がそれぞれ同じ列位置にそろった表形式で出力されます。分の値は秒数を四捨五入します。

履歴内の記録をクリックすると詳細画面が表示されます。前日以前の参照専用履歴でも、作業時間、開始・終了時刻、タスク名、メモを確認できますが、変更・削除はできません。当日の履歴、または5分間の編集許可中は内容の変更や削除ができます。開始・終了時刻または作業時間を変更し、開始・終了時刻から求めた時間と入力した作業時間が異なる場合に限り、保存時にどちらを使用するか選択できます。既存の差異だけでは確認画面を表示しません。

履歴の追加・編集では、未入力の開始・終了時刻欄に初めて触れると現在時刻が入ります。履歴追加を含む入力フォームは `Ctrl+Enter` でも確定できます。

当日の履歴から計測を再開した場合は、履歴に保存されていた開始時刻を維持します。再開操作を行った時刻が新しい開始時刻になることはありません。

履歴から計測を再開しても、元の履歴は削除されずに残ります。再開した計測を「次の作業に移る（履歴へ追加）」で保存すると、元の履歴と同じIDの記録を更新します。 更新後は、再開に使用していたタイマータブを自動的に削除します。再開中は計測画面、タイマータブ、対象の履歴に専用の枠色と「計測再開中」を表示します。

タイマーの開始を忘れた場合は、履歴画面の「作業履歴を追加」を押してください。日付、タスク名、開始・終了時刻や作業時間を入力すると、通常のタイマー記録と同じ履歴に追加されます。過去履歴の編集許可中は、選択中の過去日付にも作業履歴を追加できます。

## 履歴の保存について

履歴はサーバーには送信されず、使用中のブラウザのストレージに保存されます。そのため、同じ公開URLを同じ端末・同じブラウザで開いた場合に限り、以前の履歴を参照できます。

**ブラウザのキャッシュ、Cookie、サイトデータ、閲覧データなどを削除すると、保存されている履歴も消える可能性があります。履歴を残しておきたい場合は、このサイトのデータを削除しないでください。**

バックアップのインポート時は「データを結合」または「すべて置換」を選択できます。結合では現在のタイマー状態と設定を維持し、作業履歴・日別メモ・出退勤記録を追加します。同じ履歴ID、または同じ日付の日別メモ・出退勤記録がある場合は、現在のデータを優先します。現在の作業履歴・日別メモ・出退勤記録がすべて0件の場合は選択画面を省略し、自動的に置換します。

次の場合も履歴を参照できなくなることがあります。

- 別の端末や別のブラウザからアクセスした場合
- シークレットモード／プライベートブラウズを使用した場合
- GitHub PagesのURLやドメインを変更した場合
- ブラウザを初期化またはアンインストールした場合

## ファイル構成

- `index.html`：画面構成
- `styles.css`：デザインとレイアウト
- `app.js`：タイマー、履歴、ブラウザ保存の処理

## 動作環境

最新版のGoogle Chrome、Microsoft Edge、Safari、Firefoxなど、`localStorage`と`dialog`要素に対応したブラウザを使用してください。
